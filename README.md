# 振兴杯球场巡礼 · 武汉大学足球协会

武汉大学足球协会为"振兴杯"大学生足球联赛制作的球场巡礼网站（纯静态）：巡礼 **4 个振兴杯比赛球场**（奥场 / 桂操 / 工操 / 信操），配套官方渠道照片、2025 赛事速览与冠军领奖台、历史时间线、地图与 3D 球场。

> 四大球场（振兴杯比赛场地）：
> **九一二操场**（文理学部）· **桂园田径场**（文理学部）· **工学部田径场/松园操场**（工学部）· **信息学部田径场/竹园操场**（信息学部东区）

## 使用方法

- **直接打开**：双击 `index.html` 或 `3d.html`（照片与全部 JS/CSS 库均已本地化：`images/`、`js/vendor/`、`css/vendor/`，页面离线可运行；仅地图的高德瓦片需联网）。3D 页也可从主站导航或卡片「🎮 3D」按钮进入。
- **本地服务器（可选）**：`python -m http.server 8000` 后访问 `http://localhost:8000`。
- **部署**：整个文件夹丢到任意静态托管（GitHub Pages / Vercel / 对象存储）即可。

## 发布到微信公众号

公众号文章正文无法直接运行自定义 JS 页面，标准做法是「部署到公网 + 阅读原文外链」：

1. **开启 GitHub Pages**：仓库页 → Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。约 1 分钟后得到 `https://<用户名>.github.io/<仓库名>/`。
2. **文章内引流**：公众号后台编辑文章 → 「阅读原文」填上述链接；文中插入球场照片 + 引导语（如"点击文末阅读原文，进入 3D 球场巡礼"）。也可把链接挂到公众号「自定义菜单」。
3. **注意**：
   - github.io 在部分网络环境下较慢或被拦截，发布前请用**手机流量 + 微信内置浏览器**各实测一次；
   - 若不稳定，换国内可达的静态托管（腾讯云 COS 静态网站 / EdgeOne Pages / Gitee Pages），整个文件夹原样上传即可，无需改代码；
   - `og:image` 分享卡片图目前是相对路径，部署后可改成完整 URL（`https://<域名>/images/912-aerial-1.jpg`）。

移动端已适配：3D 页自动识别手机并降配（阴影 1024、跳过后期泛光与 MSAA、观众/花瓣/树木减量、像素比上限 1.5）；主站响应式布局、锚点避开吸顶导航、灯箱支持左右滑动翻页。

## 功能

- 🗺️ Leaflet + 高德瓦片（卫星影像 / 电子地图一键切换，GCJ-02 对齐）
- 📍 4 个编号标记 + 按矢量数据尺寸绘制的足球场草坪虚线框；弹窗缩略图直达详情卡片
- 🔧 校准模式：拖动标记微调位置，自动存 localStorage（可一键重置）
- 🏫 按学部筛选卡片，另有九一二操场、桂园操场快捷筛选；灯箱大图浏览（键盘 ←/→/Esc）
- 📜 绿茵时间线（1930s–2025）、新生杯/振兴杯/五人制/足协杯赛事卡片
- 🎮 **3D 球场**（`3d.html`）：three.js 按实测数据程序化重建四块场地——400 米标准跑道与足球场实尺纹理（Canvas 按 10px/米绘制）、球门球网、看台、灯塔，以及各地标示意（行政楼/宋卿体育馆/工学部体育馆/信部图书馆等）；支持球场切换、白天/夜晚、自动旋转、轨道相机
- ⚽ 其他场地（梅园操场、附中/附小运动场）可在地图叠加显示并定位

## 目录结构

```
whu-football-viz/
├─ index.html          # 主站页面（地图 + 照片 + 时间线）
├─ 3d.html             # ★ 3D 球场页（three.js r147 传统脚本加载，双击 file:// 可直接打开；#场馆id 直达）
├─ css/style.css       # 主站样式
├─ css/3d.css          # 3D 页样式
├─ js/data.js          # ★ 全部数据：球场、坐标、照片、时间线、来源（改这里即可增删内容）
├─ js/app.js           # 地图/渲染/交互逻辑（含 WGS-84→GCJ-02 转换）
├─ js/three-app.js     # 3D 场景：跑道/草坪实尺纹理、球门、看台、灯塔、地标、日夜切换（非 ES Module，兼容 file://）
├─ js/vendor/          # 本地化库：three.min.js（r147）、OrbitControls.js、leaflet.js（1.9.4）
├─ css/vendor/         # 本地化 leaflet.css 及其 images/ 图标
├─ images/             # 43 张照片（官方渠道下载，图注与来源见 data.js）
├─ data/               # 研究原始数据（矢量瓦片解析结果 labels-dump.txt、mvt-fields.txt、样式 JSON 等，可删）
├─ _verify/            # 高德卫星瓦片缓存（定位核对用，可删）
└─ README.md
```

## 数据与坐标说明

- **场地坐标**：提取自武汉大学官方"四季电子地图"（Urban Computing & Visualization Lab，`http://139.224.215.240:1234/`）页面公开加载的 Mapbox 矢量瓦片（`playgrounds` 操场多边形、`sportsline` 跑道线、`poi` 命名标注），坐标系为 **WGS-84**；前端用标准 eviltransform 算法转 **GCJ-02** 以匹配高德底图。
- 每块场地的中心取"球场草坪"多边形质心，并与 POI 标注（九一二操场/桂园田径场/竹园田径场/松园田径场）交叉验证。
- 足球场尺寸（来自矢量数据）：九一二 108×66m、桂园 110×71m、工学部 107×66m、信操 102×56m。
